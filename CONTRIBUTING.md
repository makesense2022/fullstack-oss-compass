# Contributing

This repo is currently a personal training project, but it is structured as if it could become public.

## Change Rules

- Keep each PR focused on one workflow or one API behavior.
- Add or update seed data when the project list changes.
- Prefer small tests and smoke checks over large rewrites.
- Record why a new open-source target is worth a senior frontend engineer's time.

## PR Checklist

- The app still starts with `npm run dev`.
- `npm run check` passes.
- New project data includes repo URL, fit, skills, and a first action.
- New learning docs include a concrete output, not only a topic list.
